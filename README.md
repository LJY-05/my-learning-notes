# StudyBuddy 教综学习管理工作台

一个在 Windows 10/11 浏览器中使用的中文个人学习管理工具。React + TypeScript + Vite；无需数据库、账号或云服务器。所有学习记录保存在当前浏览器的 localStorage。

## 第一次启动（零基础）

1. 安装 **Node.js 22 LTS**（Windows 安装版，安装过程保持默认选项）。安装完成后重新打开终端。
2. 解压项目到普通文件夹，例如 `D:\StudyBuddy`。不要直接在压缩包内操作。
3. 双击 `启动StudyBuddy.bat`。首次运行需要联网安装依赖，等待终端显示启动成功。
4. 在 Edge 或 Chrome 打开 **http://localhost:5173**。
5. 使用时保留终端窗口。退出时关闭终端即可，下次仍双击该文件启动。

如果系统提示未知发布者，可先用记事本检查 BAT 文件；脚本只进入项目目录、检查 Node.js、安装锁定依赖并运行 Vite。

也可手动启动：在项目文件夹地址栏输入 `cmd` 并回车，然后依次运行：

```bat
npm ci
npm run dev
```

若提示 `npm 不是内部或外部命令`，请安装 Node.js 并重启终端。若提示端口被占用，先关闭之前运行的 StudyBuddy 窗口。**请固定使用 localhost:5173**，更换浏览器、端口或使用 127.0.0.1 会进入不同的本地存储空间。

## 日常使用

- **首页**：选择日期查看学习安排，查看整体进度、逾期任务、到期复习与错题提醒。
- **每日计划**：28 天全部任务；勾选新背、3600和计划真题分别记录。再次点击已勾选项，可确认撤销，操作历史保留。
- **任务详情**：修改学习标题、安排日期、掌握程度和备注，查看原始任务和操作历史。
- **智能顺延**：选择起始日期，将未全部完成的逾期计划按顺序每天安排一项。已经完成的子项保持完成，原始日期与进度分母不变。
- **遗忘曲线**：完成新背后，按实际完成日 +1/+3/+7/+14/+30 天创建五个唯一复习节点。重复操作不重复生成。撤销新背只移除尚未完成的复习；已完成复习保留，重新完成新背时也不重复生成这些节点。
- **错题本**：添加、编辑、删除知识点，记录分类、错因、掌握程度和复习日期。点击完成复习保留本次记录，并安排 3 天后再次复习；已掌握错题不进入首页到期提醒。
- **真题训练**：记录套卷、日期、正确数、总题数、用时和薄弱模块，自动计算正确率。此模块是实际套卷日志，与28天计划中的“真题安排完成”分开保存，避免记录一份日志就误勾选某一天的任务。
- **学习日历**：切换月份，查看安排、实际背诵完成和复习。点击日期查看详情。
- **学习统计**：实际完成数量和原计划完成率按日统计，计划完成率按原计划日期分周统计，并汇总模块进度、未掌握知识点及套卷平均正确率。

## Excel 来源与日期处理

初始数据仅来自上传的《28天教综四线联动打卡表.xlsx》，原文件保存在 `public/原始学习计划.xlsx`。四张工作表是：

1. 28天背诵计划：D1–D28，模块、主背、资料定位、核心目标、3600联动、复习联动、真题、掌握度与备注。
2. 遗忘曲线复习：D1/D3/D7/D14/D30，与每日计划使用同一 Day 关联。
3. 高效背书法：看→合→说→对→再说→题、掌握度标准与资料使用方式。
4. 3600与真题联动：一轮收尾→章节二刷→真题，每周两套；原28天计划共6套。

**原文件实际日期为 10/08–11/04。依用户要求，项目将相同 D1–D28 任务映射至 2026-10-21 至 2026-11-17。** 原表日期、四线关系和任务全文保留。系统当天日期取自电脑本地日期；过去日期不会自动标记完成。复习依据实际打卡日期计算，不直接把原表复习日期当成已执行记录。

初始完成数为零。整体进度分母为 **62 项**：28次背诵 + 28次3600联动 + 6次计划真题。自动生成的复习另行统计，不改变原计划分母，顺延也不会新增任务。

## 备份与恢复（重要）

右上角 **导出 Excel** 会下载全部学习数据，包括原始四表、当前学习记录、复习、错题、套卷及机器可恢复的完整数据工作表。

- 在另一台电脑或浏览器打开项目，点击 **导入** 并选择导出的 Excel，即可恢复。导入会要求确认覆盖，建议先备份当前数据。
- 也支持导入原格式原始 Excel（必须含「28天背诵计划」与完整 D1–D28 行）。此模式按用户指定的日期范围重新开始，完成状态全为未开始，需要确认。
- 不支持任意格式 Excel。请保留导出文件的 `StudyBuddy数据` 表，不要手动编辑机器备份字段。
- 数据只在当前浏览器，不会同步到云端；清理浏览器网站数据、使用隐身窗口或更换网址可能导致看不到记录。**建议每天导出一份备份。**
- 上传导入和导出均在本机浏览器中处理，不上传到服务器。

## 开发和验证

```sh
npm ci
npm run dev
npm run build
npm test
# 浏览器端测试（首次需要安装 Chromium，已有系统 Chromium 时可直接运行）
npx playwright install chromium
npm run test:e2e
```

构建产物在 `dist/`。用 `npm run preview` 可在同一固定端口预览构建版本；先关闭开发服务。请勿直接双击 `dist/index.html`。

`src/model.ts`：初始模型、日期运算、去重复习生成、历史顺延与进度计算。
`src/main.tsx`：七个模块、浏览器存储、Excel导入导出。
`src/seed.json`：由原始工作簿逐行提取的任务与四表内容。
`tests/app.spec.ts`：真实浏览器端工作流及手机宽度检查。

项目使用系统字体，无需外部字体服务。依赖安装需要联网；安装完成后日常本地使用无需联网。
