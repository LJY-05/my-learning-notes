# StudyBuddy · 学习知识工作区

面向2027届道德与法治教招备考的学习管理应用。React + TypeScript + Vite、Tailwind CSS、基于 shadcn/ui 方式组织的 Radix 可访问组件、Lucide、Recharts；Express + Zod + SQLite，Drizzle 类型化表定义与 SQL 构造，Node 原生 SQLite 驱动负责事务。默认无需 API Key，Mock 规则助手可直接运行。

## Obsidian 风格工作区更新

界面采用炭灰背景、紫色强调色、窄工具栏、可折叠导航与可关闭工作区标签。宽度1550px及以上显示右侧学习上下文/任务属性；手机保留标签与抽屉导航。新数据库默认深色，已有用户的主题选择保留，可在右上角切换。

教案、逐字稿、错题解析及备注支持Markdown编辑和预览，聊天内容也支持Markdown。预览使用DOMPurify清理HTML，不执行脚本，也不加载笔记中的外部图片。本次更新不修改已有计划或记录，不重建数据库，Mock AI保持可用。

已有Windows用户升级：先在设置导出完整JSON备份，再关闭旧启动窗口。将新版本解压到另一个文件夹，用其中的BAT启动，随后在设置恢复JSON备份。不要删除或覆盖旧项目的`data`目录；确认新版本数据正确后再整理旧文件。由于新增Markdown依赖，替换代码原地升级的用户需要重新执行`npm ci`。

已配置DeepSeek或OpenAI的用户，请把旧项目的 `.env` 安全复制到新版根目录；密钥不包含在JSON备份中。不要上传或发送 `.env`。

## Windows 10 / 11 第一次使用

1. 安装 **Node.js 24 LTS**，重新打开 VS Code 或终端。旧版本不支持本项目使用的原生 SQLite API。
2. 将完整项目放在普通目录，如 `D:\StudyBuddy`，不要直接在压缩包中运行。
3. 双击 `启动StudyBuddy.bat`；或在 VS Code 终端执行：

```sh
npm ci
npm run db:init
npm run dev
```

4. 在浏览器访问 `http://localhost:5173`，保留终端窗口。关闭终端停止前后端，下次重新启动即可。

首次启动会创建 `data/studybuddy.sqlite` 并导入正式 Excel。后续启动不会覆盖已录入数据；`npm run db:init` 可重复执行，不会重复导入同一计划。如果目录中没有正式 Excel，应用保持空数据库，在「设置与数据」上传即可。

无需安装独立数据库、Python 或编译器。Node.js 原生 SQLite 在部分版本可能提示实验性警告，不影响运行。BAT 和 Windows 步骤已按标准 cmd 编写，本次自动验证在 Linux 进行，未声称 Windows 实机测试。

## 正式计划与导入规则

初始源文件为 `public/StudyBuddy_备考计划_结合实习课表调整版.xlsx`，与用户上传文件逐字节一致。原先的 `public/原始学习计划.xlsx` 与 `src/seed.json` 仅作为旧版资料保留，不作为新版默认计划。

- 识别 **9 张表、56 天（2026-10-23—2026-12-17）、317 项执行任务**。
- 「新版每日任务_10月23起」是主执行表；原28天背诵表、遗忘曲线、周目标、月目标、背书法、联动规则和课表原文都能在「学习计划」展开查看。
- 原表不是完成凭证，任务不会因日期已过或阶段已完成而自动打卡。每日行状态不能推断各子项已完成，非明确「未开始」状态标为待确认。
- 文件 SHA-256 指纹防止重复导入；稳定任务ID由表名、日期和模块产生。修改文件再次导入只新增缺失任务，不覆盖用户修改、已完成状态、回收站或学习历史。需要整体回到备份版本时使用 JSON 恢复。
- 每日合计预计分钟保存在源表和每日负荷中。Excel 没有逐项预计分钟，任务显示「时长待补充」，不随意均分。只有填了逐项时长的任务才进入时间预算。
- 10月23日—11月5日固定课表确认有效；周四为高负荷，周二、五为强化日。其后原表建议保留，但课务标为待确认，不自动永久沿用。
- 3600第一轮和学科第一套首轮的完成只作为背景说明。学科第二套初始真实练习数为0，总量未知；不虚构完成百分比。累计记录题数也不代表唯一题目覆盖率。

导入流程为上传 → 校验与源表/任务预览 → 用户确认 → 数据库事务写入。源文件不执行任何指令。最大上传10MB；候选预览15分钟有效。

## 日常功能

1. **今日空间**：日期选择、今日任务、实际完成和学习分钟、复习提醒、近期真题与面试、专注/普通/疲惫状态。
2. **AI学习助手**：流式显示、多轮历史、真实数据工具查询、排期前后对比、用户确认后执行、操作日志。可关闭AI继续管理学习。
3. **学习计划**：每日/每周/月历/时间线/全部视图，搜索筛选，任务新增编辑、打卡撤销、改期、软删除和恢复，原表参考。
4. **遗忘曲线**：首次背诵按实际完成日产生D1/3/7/14/30唯一节点；复习与首次学习分开记录，可改复习日期和自评。重复打卡不会重复生成；撤销首次完成只移除未完成节点，已完成复习保留。
5. **错题管理**：3600二轮、6600补漏、学科一二套及行测分类，章节、标签、原因、答案、个人解析、单独AI补充字段、关联错题ID；复习轮次、再次错误、掌握度与历史，搜索筛选、删除和导出。
6. **真题与专项**：开始/暂停/重置计时，套卷与专项题量、正确数、得分、地区年份、起止时间、复盘；按真实成绩统计。不会因为记录一份练习而自动勾选计划。
7. **面试训练**：训练日期、教学目标、重难点、过程、逐字稿、本地资料位置、自评与复盘，10分钟计时。录音视频只记录路径或备注，不上传、转写或假装评估实际表现。
8. **数据分析**：真实日/周/月完成率、各科实际时间、练习正确率趋势、3600二轮/6600补漏/学科第二套/行测记录、复习执行与已掌握错题数。没有成绩时明确显示待评估。
9. **设置与数据**：姓名、可用时间、计划日期范围、第二套总量、提醒开关、主题、AI模式、逐日课务确认及临时任务、Excel与JSON管理、日志。

提醒为应用内提醒，不是系统后台推送。修改计划起止日期用于学习偏好，不会自动删除或改写已有计划。旧版浏览器 localStorage 原样保留，可在设置页导出存档；不会自动混入正式计划。

## 排期与确认

`server/scheduler.ts` 为独立确定性调度器。依据预算、已确认课务、优先级、截止日期、积压、到期复习及薄弱章节排序；强化日提高真题优先级，高负荷日延后整套真题。复习按10分钟/项明确标注为估计并预留时间。

候选展示：本日安排、延期至次日、缺时长保持原日三类；所有任务都有去向。它是**日期与时长预算**调度，不伪造课间钟点，因为源表没有每节课的具体起止时间。次日仍是待安排任务，不表示自动保证次日容量。用户确认后在事务中检查全局 revision、任务版本、日期及完成状态；过期方案、重复确认、已完成或被编辑的任务都会拒绝执行。

## 可替换 AI Provider

默认「Mock」是明确标识的规则助手，支持今日任务、真实进度、课表、错题与补漏建议、数据复盘、预算重排及自然语言新增任务候选，不声称具备真实模型的自由问答能力。

真实模型：复制 `.env.example` 为 `.env`，仅在服务端填写：

```dotenv
OPENAI_API_KEY=你的服务端密钥
OPENAI_MODEL=gpt-4.1-mini
```

重启后，在设置页选 OpenAI。模型通过 **Responses API** 流式调用，支持最多6轮工具调用、失败提示和SDK两次重试。密钥不进入前端、备份或仓库；未配置时可继续使用 Mock。

支持工具：`get_today_tasks`、`get_weekly_plan`、`get_study_progress`、`get_timetable`、`get_weak_topics`、`create_task`、`update_task`、`complete_task`、`propose_reschedule`、`confirm_reschedule`、`add_wrong_question`、`generate_weekly_review`。输入使用Zod校验。模型写工具只创建候选；模型调用 `confirm_reschedule` 也没有确认权限，必须用户点击界面确认，服务端再执行并记录日志。工具执行错误返回给模型，不能当作成功。

OpenAI外网请求需允许 `api.openai.com`。本次没有使用真实密钥，因此真实模型联网、配额和回答质量未实测；Mock、确认机制和普通功能均有自动测试。

## 数据库、备份与安全范围

数据库迁移位于 `server/001_init.sql`，启动时幂等应用。`server/schema.ts` 为Drizzle类型化表；`server/db.ts` 使用原生SQLite同步事务、WAL、外键、唯一约束及乐观版本检查。领域JSON由Zod完整校验，实体ID、复习节点、导入批次和课表日期有唯一约束。14个要求实体及候选排期独立存表。

- **完整JSON备份**：所有任务、事件、错题、练习、教案、源表、课表、偏好、聊天及日志，校验后显式确认覆盖。恢复失败回滚。建议每日导出一次。
- **Excel导出**：原表和当前任务、错题、练习、复习。用于阅读核对；完整恢复请用JSON。
- **原始数据库备份**：先停止服务，再复制 `data/` 目录，不要运行中仅复制主 `.sqlite` 文件而漏掉WAL。
- 数据存于服务端本机SQLite，浏览器刷新或更换浏览器不会丢失。不提供云同步、多人账号或远程访问登录。
- API默认仅监听127.0.0.1；Vite用于开发预览。使用HttpOnly/SameSite会话Cookie、跨站请求拒绝、显式写意图头、Zod校验、参数化SQL。它是个人本机工具，**不要直接作为多人公网服务部署**。后续远程部署需补充账号鉴权、HTTPS和数据隔离。

```sh

npm test            # 领域/导入/排期/事务/工具与旧模型回归
```

```sh

```

## 接入 DeepSeek（可选）

1. 在官方开放平台 https://platform.deepseek.com 注册并登录。网页版聊天与API服务分开，是否需要充值及费用以平台当前说明为准。
2. 在API密钥管理页创建密钥，只保存在自己电脑上，勿发送给他人或写入GitHub。
3. 停止StudyBuddy，在项目根目录（与package.json同级）复制 `.env.example`，将副本命名为 `.env`，用VS Code打开。
4. 在 `.env` 中填写 `DEEPSEEK_API_KEY=你自己的密钥`，保留 `DEEPSEEK_MODEL=deepseek-chat`。不要使用 `VITE_` 前缀，不要将密钥填入聊天输入框。
5. 保存后重新启动，在「设置与数据 → 助手模式」选择「DeepSeek · 中文学习助手」，再打开AI学习助手发送消息。

后端使用官方 `https://api.deepseek.com` 的 Chat Completions 流式接口，保留真实数据工具、最多6轮调用、SDK两次重试及用户确认机制。401提示检查密钥，402提示检查API余额，429提示稍后重试。模型名称可通过服务端环境变量调整；别名是否可用以官方当前文档为准。

密钥不进入前端、状态接口或备份。普通学习功能和Mock继续可用。本项目自动测试使用模拟HTTP响应验证DeepSeek协议、分片工具参数、确认保护和失败处理；没有使用用户密钥，因此不代表真实账户联网/余额验证已通过。云环境使用真实DeepSeek时需要允许 `api.deepseek.com`。


## 任务用时修复与专注计时（2026-10-26）

“预计分钟”是计划值，“实际学习分钟”是累计实际用时，两者可不同。预计值留空或填0统一表示待补充，不再妨碍保存实际值；仍拒绝负数。不需要修改原Excel，AI调整后的自定义任务同样适用。

- 点击顶部「专注计时」选择任务，或点击任务右侧的时钟图标，也可以在任务详情中打开计时器。
- 支持正计时、倒计时、15/25/45/60分钟快捷值和自定义分钟；支持暂停、继续和清空未保存草稿。
- 计时按时间戳差值计算，后台标签页不会因为计时回调变慢而漏算；关闭面板后有底部计时条。刷新后从本浏览器草稿恢复。浏览器关闭、系统休眠期间仍按时间差推算；休息前请暂停。
- 倒计时到零显示提示并停止累计，不自动打卡；保存也不改变任务完成状态。单次及单任务累计用时上限24小时。
- 点击「保存用时」才写入SQLite，按秒记录，追加到已有实际用时；按任务、唯一计时ID和日期防止重复保存。写入失败时草稿保留，可重试。
- 跨午夜按浏览器本地实际日期拆分记录，而不是按任务原计划日期记账。首次手动填写的实际分钟也在未打卡时进入实际时长统计。
- 打卡不重复累计已记录的用时；撤销完成不会删除独立的手动或计时记录。
- 任务详情显示用时历史。手动修改「实际学习分钟」是更正累计总量，会以本次保存日期建立新的手动记录，原事件保留并标注为已替代，不再重复计入统计；后续计时继续追加。
- 累计任务分钟显示到两位小数，统计汇总显示到一位小数，原计时事件保留整数秒。完整JSON备份包含已保存的计时与更正历史；未保存的计时草稿仅在当前浏览器，请升级或清理浏览器前先保存。
