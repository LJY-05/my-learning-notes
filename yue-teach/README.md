# 粤教上岸 YueTeach

独立于 StudyBuddy 的广东教招与教育时政个人网站，也打包为 Windows 桌面应用。Notion 风格的侧栏、文档阅读区、米白与灰绿配色；使用系统字体栈，Windows 不附带苹果商业字体。

## 下载与打开（Windows 10 / 11，x64）

1. 登录 GitHub，打开 [Windows 构建页面](https://github.com/LJY-05/my-learning-notes/actions/workflows/yue-teach-windows.yml)，选择最新的绿色成功运行。
2. 在底部 Artifacts 下载 **YueTeach-Windows**。解压外层 ZIP，再解压里面的 `YueTeach-1.0.0-win-x64.zip`。
3. 保留完整文件夹，双击 **YueTeach.exe**。不需要安装 Node、VS Code，也不用自己启动后端。
4. 顶部菜单「粤教上岸 → 创建桌面快捷方式」，以后从桌面双击打开。创建后不要移动或删除程序文件夹；移动后重新创建快捷方式。
5. 「来源与更新」查看实际采集结果；「个人档案与设置」可复用本机 StudyBuddy 的 DeepSeek 密钥，或自己填写。密钥不在前端回显，不要发给别人。

这是便携包，没有商业代码签名。应核对自己的仓库、成功构建和包内 SHA256SUMS；不要关闭杀毒软件。Code → Download ZIP 是源码，不是上述桌面成品。

## 已有功能

- 默认档案：思想政治教育、2027 届本科、**初中政治教资**、学位待确认；城市广州、深圳、惠州、肇庆。档案可修改。
- 招聘筛选：地区、全文关键词、本科线索、专业线索。逐项列出学历、专业、毕业身份、教资、学位的核对提示。**没有“已符合报考条件”的自动结论**。同一公告多个岗位，必须看岗位表。初中教资不会直接匹配高中要求。
- 官方来源：广东教育厅、省政府、广州/深圳教育及人社部门、惠州/肇庆政府、教育部，共9个入口。单篇显示原文、来源、识别出的发布日期、附件入口、笔记和收藏。
- 自动更新：应用打开时补查，每6小时再检查；关闭或关机期间不运行。每天按北京时间切换练习。失败、部分失败、模板未识别均显示；失败时保留已有记录，不伪造新闻。
- 每日目标15题：只用**近90天广东地区**（广东及四市）的非招聘正文。教育部材料用于政策阅读，不混入广东本地每日题。已经生成的当日题目固定，不覆盖已答记录。
- 免费模式：原文数字填空单选题，原句可核对。每篇最多3题，不用日期题凑数。少于15题时显示实际数量。
- DeepSeek模式：按提供的文章生成单选、多选、判断，检查结构、来源URL和连续引用是否存在。**引用存在不保证推理正确**，题目均标记未经人工审题，解析与有效原文冲突时以原文为准。生成使用自己的API额度；余额或网络错误明确显示。没有密钥不调用付费服务。
- 服务端评分、提交前隐藏答案、重复提交幂等、多选全对计分、错题回看、本机保存、JSON导出（不含密钥）。

## 自动采集范围与边界

这是个人使用的轻量采集器，不是商业全量资讯库。每次从官网首页及最多3个相关栏目发现链接，单来源最多读取10篇新的文章，逐篇请求，有12秒超时、3MB上限、安全跳转和官方域名限制。来源配置在 `sources.mjs`。

独立区县网站、动态页面、验证码、附件岗位表、正文模板改版可能漏收。目前支持的域名体系是 `gd.gov.cn`、`gz.gov.cn`、`sz.gov.cn`、`huizhou.gov.cn`、`zhaoqing.gov.cn`、`moe.gov.cn` 及其子域名，**不等于覆盖所有区县**。可在「来源与更新」手动导入这些官方域名下的文章链接。PDF、Word、Excel附件只提供官方入口，不自动读取资格条件。

发布日期不是实施日期。不自动认定某政策仍有效，也不把文章标记为“必考”。报名截止、政策修订或废止、2027届范围、专业代码和最终资格，均需对照招聘公告、附件及后续更正。

截至2026-10-27，开发环境访问上述官网被网络代理拒绝，**尚未完成这些官网的实时连通性与最新内容验证**。自动采集代码及失败展示有本地夹具测试，不能把它说成全站采集已验证。首次打开应查看每个来源状态；测试数据不放入成品数据库。没有人工写入“最新时政”示例。

## 数据位置

Windows桌面版：`%APPDATA%\YueTeach`，菜单可直接打开。SQLite保存资料、档案、答题、笔记；`ai-config.json`保存DeepSeek密钥，**是本机明文文件，不是系统钥匙串加密**。JSON导出不含密钥。更新程序保留此目录即可，不要用 StudyBuddy 数据库覆盖本程序数据库。

复用旧密钥仅在点击设置中的按钮后，读取 `%APPDATA%\StudyBuddy\.env` 内的 `DEEPSEEK_API_KEY`，复制到本程序；不更改旧文件，不读取或迁移学习记录。若没找到配置，可手动填写。

需要完整本机备份时，关闭应用后复制整个数据目录。JSON导出用于资料留存，本版没有JSON自动恢复入口。

## 开发运行

Node.js 24+：

```sh
cd yue-teach
npm ci
npm start
```

浏览器打开 `http://127.0.0.1:3188`。数据默认在 `yue-teach/data`，通过 `YUETEACH_DATA` 指定其他目录。

```sh
npm test
npm run desktop
npm run dist:win
```

桌面内部使用Electron内置Node24和独立子进程，绑定随机本机端口；私密令牌隔离API，稳定的 `yueteach://app` 来源，renderer无Node权限、启用沙箱。退出应用停止子进程。开发依赖不进入成品用户数据库。

在仓库根目录执行桌面验收（需要根目录 `npm ci` 提供 Playwright）：

```sh
node yue-teach/test/smoke.mjs
node yue-teach/test/ui.mjs
```

可把打包后的可执行文件路径作为第一个参数，验证实际成品。Linux测试用headless Ozone；正式Windows保持沙箱。Windows GitHub Actions运行核心测试和实际Windows成品smoke/UI测试，再生成带校验和的下载包。

测试材料全部明确标记为虚构夹具，既不是实时新闻，也不进入成品。DeepSeek采用格式及原文匹配单元测试，没有使用真实密钥调用付费模型。
