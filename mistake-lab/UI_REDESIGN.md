# MISTAKE LAB 视觉重设计

采用已安装的 Frontend Design 为主设计依据；React Best Practices 用于组件组织与延迟加载，Playwright 用于实页审查。没有额外安装设计库、字体或运行远程安装脚本。

## 设计定位

个人学习手册与书桌。保持用户确定的韩系极简、奶油白与森林绿，通过书封、书脊、便签和原书纸面建立产品辨识度。缩减大侧栏与装饰统计组件，让原书、错题与复习成为可直接操作的主体。

- 奶油纸 `#F7F5EF`：页面底色。
- 森林绿 `#244C3E`：主行动、书封、品牌标记。
- 深墨绿 `#283D34`：正文和中文标题。
- 鼠尾草绿 `#D1DDBD`：书封、索引与选中状态。
- 雾蓝 `#DBE7EA`：辅助书封与 AI 模拟体验入口。
- 暖白 `#FFFEFA`：题卡、纸页和校对弹层。

DM Sans + 中文系统字体承担标题、正文和控件；Cormorant Garamond 仅用于数字、局部注记和英文辅文。中文成为主要信息层级，正文与控件放大，移动端表单使用 16px 字体。

## 构图

桌面：

```text
[窄导航] [品牌 / 搜索 / 本地状态]
         [中文标题 + 复习行动] [可点击书封和便签]
         [紧凑学习记录]
         [原书 / 错题集书架                 ]
         [最近的题目              ] [思路空间]
```

手机：品牌和抽屉菜单在顶部，标题与书封上下排列，书架双列；原书和错题卡单列。导入表单把同类信息并排，保持题本、章节等长字段全宽。

## 修改范围

- 新的 M 字形品牌标记与图标，保留品牌名称 MISTAKE LAB。
- 首页从原有欢迎卡、圆形掌握度、统计块与周图改为可操作书桌：复习、原书、真实书架、最近题目和 AI 模拟体验入口。
- 88px 窄导航，中文主标签；手机使用抽屉并支持 Escape 关闭。
- 错题卡使用纸卡层次、学科色、较大预览和文字，保留收藏、筛选、排序和详情入口。
- 阅读器减少周边占用，提高原书显示面积；统一工具条、缩放、页码、采集篮与核对弹层的视觉。
- 教辅导入使用实际可点击及拖放的 PDF 选择区，保留输入校验、页范围和人工确认。
- 题目详情、复习中心与 AI Studio 共用纸面、字体、圆角和交互状态。
- 仅对鼠标交互提供细微抬起和书封响应，尊重 reduced-motion；没有新增循环入场动画。

没有改变 OCR、切题、匹配、原始文件归档、坐标计算和答案人工确认算法。此轮视觉更新不代表已完成 Windows OCR 适配，也不扩大真实资料准确率的既有验证结论。

## 验证

- `npm run test:browser`：8 项全部通过；覆盖原图哈希与逐像素裁剪、缩放、真实 OCR 核对门禁、跨页排序与合并、PDF 解析/答案待确认、手机触屏采集和边界修改。未处理页面异常为零。
- `npm run typecheck`：通过。
- `npm run build`：通过。
- Playwright CLI 实页审查：1440px 桌面、768px 平板、390px 手机；首页横向宽度与视口一致，手机导航可展开并用 Escape 关闭，桌面首页/题库/阅读器控制台无错误。
- 视觉审查发现并修正平板标题孤行和书封对注记的遮挡；手机导入表单按同类字段双列排布。
- 预览图：`output/playwright/redesign-home-desktop.png`、`redesign-library-desktop.png`、`redesign-reader-desktop.png`、`redesign-home-tablet.png`、`redesign-home-mobile.png`、`redesign-import-mobile.png`。
