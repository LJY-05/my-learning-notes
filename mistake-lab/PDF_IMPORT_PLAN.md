## 实施方案与已落地能力

新增独立 `/import` 页面；沿用奶油白、森林绿、鼠尾草绿、现有字体与留白。左侧是顺序草稿，右侧把裁剪证据和可编辑文字放在一起；移动端改为横向条目导航。

1. **范围受控**：网站接受最多 128 MiB 的原始 PDF，但一次只解析明确选定的连续 1–5 页。聊天附件下载的 32 MiB 上限与网站上传上限不同。上传并保存整份 PDF 不等于处理整本。文件大于网站上限时也需拆分章节。
2. **拆页和来源**：PyMuPDF 渲染所选页，读取全文档总页数和内嵌书签目录（最多 300 条），保留 PDF 页索引、PDF 页标签、用户指定的纸面起始页码及归一化文字行坐标。没有内嵌书签时不虚构目录，章节需人工指定。
3. **文字提取**：优先 PDF 文字层；少于 20 个字符且用户启用回退时，调用本机 Tesseract 执行页面 OCR。PDF 图片和内嵌文字均当作数据，不执行文档指令。没有大模型自动推断。
4. **规则切题**：显式选择单栏或双栏（先左后右），识别行首阿拉伯题号与明确题型标题。同章不同题型可从 1 重新编号；不由选项个数推测题型。无题号片段保留为待校对续片或杂项。复杂表格/不规则多栏/没有标记的题号可能切错。
5. **人工修正与跨页**：逐条查看原始文字、裁剪区域、PDF 页、纸面页和像素坐标；支持直接改题干、选项、章节、题号、题型、答案和解析。归一化边界可微调并重裁；也可回原阅读器重新框选。相邻草稿可显式合并，也可拆开重做；误排除片段可恢复。最多 5 段，同书同章节同资料类型；跨页续题不自动归档。每次编辑或合并撤销核对状态。
6. **批量归档**：仅归档已逐条勾选“文字”和“来源完整性”的草稿；批次里任一目标不合格整次不写。每个章节有独立批次与可恢复草稿。同一本 PDF 后续选择其他章节继续，既有题目不覆盖。
7. **解析与匹配**：先提取显式题号、答案标记及 `【解析】` 分界；不能可靠分隔的答案留空，要求人工补齐。经校对的答案以独立条目保存；按书名、章节、具体题型、题号生成候选，重复候选明确标记歧义。所有候选均为 pending，不自动写入题目。复用已测试的资料整理弹窗进行人工改目标、确认、拒绝和覆盖保护。
8. **保留资料**：原始 PDF 完整字节、渲染书页、单题裁剪、坐标、原始提取文字、编辑后的文字/选项、标准答案/解析及人工核对时间。PDF 裁剪基于渲染页，明确标记不是扫描原图像素。PDF 的内嵌原始扫描图未单独提取；原始 PDF 本身完整保留。

## 依赖与运行

现有 Python 3 / PyMuPDF 1.26.6、Tesseract 5.5.0 及已校验的官方中文/英文模型。测试 PDF 使用环境自带 reportlab 生成。没有运行来源不明的脚本，没有新增 npm/Python 下载依赖。

PDF API 是 Node Route Handler，使用固定 Python 脚本和参数数组，不调用 shell；临时目录在成功、失败、取消后清理。每个进程同时接受一个 PDF 请求，有文件大小、页数、渲染尺寸、输出及超时限制。前端可取消处理。此为单用户原型，尚不具备生产级鉴权、隔离队列、持久对象存储和多用户配额。

## 验证依据

所有 PDF 验收输入均在 `output/test-fixtures`，文件名以 `synthetic-` 开头，是专门构造的测试文件，**不是用户教辅资料，也不代表用户文件的识别准确率**。

- 三页中文文字层题本：第一章含四种题型、一道跨页多选题；第三页是第二章同号题。内嵌两条目录书签。
- 一页答案 PDF：分别含单选、多选、判断、填空答案与解析。
- 一页扫描 PDF：将此前明确标注的合成中文页面嵌入 PDF，强制覆盖 OCR 回退路径。

最终验证结果：

- `npm test`：28 项全部通过（原有 18 项 + 新增导入/原生 PDF 10 项）。
- `npm run test:ocr`：2 项全部通过，实际 Tesseract 识别与取消清理。
- `npm run test:browser`：8 项全部通过（原有 5 项回归 + 新增 3 项 PDF 浏览器/API 流程），无未处理页面错误。
- `npm run typecheck` 和 `npm run build` 均通过。
- 浏览器验证了完整 PDF 的 SHA-256 字节保留、两页合并后 A–D 选项与页码保留、合并错误可拆开重做、四种题型入库、答案只生成 pending、第二章同号题不串答案、移动端边界修正撤销核对状态。
- PDF 原生测试覆盖元数据/内嵌目录、指定页渲染和坐标、超范围/伪文件拒绝、失败或取消后的临时目录清理。
- 原有图像测试继续验证原始图片区域逐像素一致、缩放与触屏框选、核对及答案类型约束。

截图：`output/playwright/import-center-desktop.png`、`output/playwright/import-center-mobile.png`。生产构建已在 3100 端口启动，新入口为侧栏“教辅导入”或 `/import`；此云环境未提供可生成公网预览链接的工具。

## 尚未实现或无法验证

- 六份用户原始 PDF 的目录与真实排版、识别准确率、真实题目和答案的关联准确率：因下载上限无法验证。
- 扫描目录的自动重建、章节语义推断、不规则多栏/公式/表格的通用结构恢复、自动识别纸面页码、无需人工介入的跨页续题推断：未实现。
- Word、加密 PDF 解锁、整本无人值守批处理、云存储/云同步：未实现。
- 无分隔的答案速查表、同一行多个题号答案、合订本角色自动区分、复杂表格解析：可能不能自动切开，必须人工补充或回原书采集，不得视为已支持。
- 原有图片上传、缩放、精确框选、核对门禁与答案确认核心算法保留；阅读器仅新增按来源角色区分题本/答案页的过滤，避免同书同页码混排，执行旧浏览器用例回归。
