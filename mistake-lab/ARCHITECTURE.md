# 真实书页处理架构

## 分层实体

| 实体            | 责任                                                                                |
| --------------- | ----------------------------------------------------------------------------------- |
| SourceAsset     | 完整原始文件，区分习题册与答案资料                                                  |
| BookPage        | 阅读预览、原书页码、章节和 sourceId                                                 |
| CaptureFragment | 单段原图裁剪、来源页、比例区域、像素边界、原始尺寸、OCR 原始结果                    |
| CaptureDraft    | 同书最多 5 段、可编辑字段、人工核对状态；持久化但未归档                             |
| QuestionRegion  | 书页区域与收集入口，区分示例/手动/OCR                                               |
| Question        | 人工核对题目、独立选项、多个原图片段、合成预览和提取来源；旧 pageId/rect 兼容首片段 |
| AnswerEntry     | 独立解析、具体题型、题号、来源、修订号                                              |
| MatchCandidate  | 待审/确认/拒绝/历史关联、版本与确认快照                                             |

旧数据通过 upgradeData 保留；新增字段可选。个人工作区客户端挂载，避免服务端演示计数与浏览器 IndexedDB 的 hydration 冲突。

## 采集流

上传少量图片并标页码 → 原文件与阅读预览分开 → 框选比例坐标 → 基于原文件尺寸计算像素区域 → 暂存独立片段 → 继续翻页、排序 → 按需 OCR → 保留只读输出 → 用户应用建议与编辑 → 人工核对文字/选项、题型/完整性 → 归档一道题，答案保持空白。

显示缩放不参与原图裁剪计算。像素边界向外取整不足一像素。合并预览最大宽 1400、高 12000，各原始 PNG 仍独立保存；可逐片段回查原书高亮。不同书不能合并，重复区域不能重复入篮。系统不自动推断续页归属或完整性。

## OCR 服务

POST /api/ocr 仅接受有限大小单片段 PNG，检查尺寸、请求体、并发和实际 Host/协议同源。通过无 shell 的固定参数运行 Tesseract，限制时间、输出与线程，支持取消；临时目录在成功/失败/取消后清理。模型来自官方固定提交，安装脚本检查 SHA-256，识别时不调用第三方。

默认中文优先，另有中英混排/英文与连续/稀疏模式。返回真实文字、引擎置信值、版本和时间，始终 reviewRequired。只对显式题号、选项标记、题型标题提出建议，不推断知识点，不用答案字母数量决定题型。

OCR 不能归档或确认答案。修改文字、OCR 输出或片段顺序会重置核对；选择题缺项或顺序不连续不能归档。源图与只读原始输出始终可查看。

## 答案流

规则范围为书、章节、具体题型、题号。未知题型不生成候选，人工改配也必须通过题型检查。单选、多选、判断、填空分别校验格式，格式合格不代表语义正确。

候选不会写入答案。人工确认后保存关联和解析快照；替换另需勾选。解析修订不静默改写旧结果，旧候选不能确认。修改题型、题号、归属或答案会解除关联，历史快照保留。

PDF 页面渲染、文字层提取/页面 OCR、规则切题和答案解析草稿已接入独立导入中心；自动全书分割仍未实现。任何 MaterialProcessor 只能返回草稿，不能绕过人工门禁。多版本教材正式接入前，应引入稳定教材/版次/章节 ID。

## 验证边界

领域、真实 Tesseract、桌面及手机测试分开执行。合成中文夹具用于可复现的精度与流程检查，不冒充用户原图。聊天附图没有文件路径或下载 ID，实际水印、表格、低分辨率和续页资料的准确率仍需原文件逐题验收。

## PDF 导入流水线

`/import` → `/api/import-pdf` → 固定 Python/PyMuPDF 脚本 → `PdfInspection`（内嵌目录、页索引/标签、渲染图与文字行坐标）→ `segmentPages` → `ImportJob.items`。`LabData.importJobs` 为可选增量字段，旧数据无需覆盖迁移。`BookPage.pdfPage/pdfLabel` 独立于纸面 `number`。原始 PDF 的 SHA-256 + 资料角色 + 统一书名构成来源标识，复用相同 PDF 的不同章节时保留旧页，不覆盖既有题目。

`ImportItem` 保存裁剪片段、原始文字、可编辑结构、答案/解析草稿、核对门禁和归档状态。边界修正、合并或拆分会撤销核对；误排除的片段可恢复。`commitItems` 在一份状态中校验整批后原子添加题目或独立答案；重复原书裁剪区域被拒绝。新答案保留原始文字、来源片段和人工核对时间。每次归档后使用旧匹配算法生成 pending 候选，导入模块仅增补歧义提示，不改变 `confirmMatch` 的校验、快照和替换语义。

页范围/文件限额、依赖、真实附件的访问阻碍及测试依据详见 `PDF_IMPORT_PLAN.md`。
