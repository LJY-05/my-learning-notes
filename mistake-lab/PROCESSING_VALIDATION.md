## 测试结果

- setup:ocr：中英文模型 SHA-256 检查通过。
- npm test：18 通过，0 失败，0 跳过。
- npm run test:ocr：2 通过，包括真实中文识别、取消后的临时文件清理。
- npm run test:browser：5 通过，0 失败，0 跳过，17.7 秒。
- npm run typecheck、npm run build：通过，生产构建包含动态 /api/ocr。
- 生产端口 3100 的 OCR 冒烟检查通过：真实中文输出，reviewRequired 为 true。

合成夹具由 scripts/make-fixtures.py 生成并明确标注“不是用户原图”。浏览器测试使用独立数据，不向用户工作区写入示例识别结果或正确答案。

## 已修复的测试问题

1. 自定义模型目录没有 TSV 配置，改为显式启用 TSV 输出。
2. 整页留白和中英竞争造成短中文选项漏读，实际按单题裁剪识别，提供中文优先和版面模式，错误需人工核对。
3. Next.js 内部 localhost 与浏览器 127.0.0.1 差异导致 OCR 被误拒绝，改为实际 Host/协议校验，保留跨来源拒绝。
4. IndexedDB 数据与服务端演示计数冲突，个人工作区客户端挂载，持续断言无未处理页面异常。
